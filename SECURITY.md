# Security policy

This is a private internal application. Do not report vulnerabilities in a public issue.

Contact the Sankari Holding IT administrator directly with the affected URL, time observed and steps to reproduce. Do not include employee records, passwords, access tokens or mail credentials in the report.

Production operators should keep the repository private, use HTTPS, rotate initial passwords, configure encrypted off-site backups, protect SMTP credentials outside Git, and update Node.js and dependencies regularly.
